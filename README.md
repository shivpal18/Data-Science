## ❤️ Heart Disease Prediction

A Machine Learning web application that predicts heart disease risk based on user-provided health parameters.

**Tech Stack:** **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Streamlit, Joblib

**Live Demo:** [Try the Heart Disease Prediction App](https://shivpal18-data-science-06-machine-learningproject2heart-7tszav.streamlit.app/)

**Models Evaluated:** Logistic Regression, KNN, Naive Bayes, Decision Tree, SVM

**Best Result:** Logistic Regression — 86.96% accuracy on the evaluated test set.

*Disclaimer: This project is for educational purposes only and is not intended for medical diagnosis.*
